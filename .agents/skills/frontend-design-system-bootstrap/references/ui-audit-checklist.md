# UI 감사 체크리스트

## 조사 범위

- 라우트별 페이지, 공통 레이아웃, 인증/오류 경계, 모달·드로어·내비게이션을 목록화한다.
- 전역 스타일, 테마 설정, 유틸리티 클래스, CSS module, inline style, 아이콘·이미지·폰트 경로를 조사한다.
- 공통 컴포넌트와 페이지 로컬 컴포넌트의 중복을 이름뿐 아니라 역할과 시각 패턴으로 비교한다.
- 모바일, 태블릿, 데스크톱의 핵심 흐름을 대표하는 화면을 확인한다.

## 발견 항목

각 항목에 `증거(파일/패턴/빈도)`, `사용자 영향`, `우선순위`, `수정 범위`, `기존 의도`를 기록한다.

### 일관성

- 동일 역할에 다른 색상, 타이포그래피, 간격, radius, 그림자, 아이콘 크기가 쓰이는가?
- 버튼, 링크, 입력, 카드, badge, 상태 표시의 variant와 state가 예측 가능한가?
- 같은 의미의 raw 값과 임의 유틸리티가 반복되는가?
- 공통 컴포넌트를 우회한 페이지 로컬 구현이 반복되는가?

### UX

- 주요 CTA와 보조 동작의 우선순위가 명확한가?
- 로딩, 빈 상태, 오류, 성공, disabled 상태가 사용자에게 원인과 다음 행동을 알려 주는가?
- 폼 label, 도움말, 유효성 검사, 오류 복구가 일관적인가?
- 내비게이션 위치와 뒤로 가기, 취소, 저장 동작이 예측 가능한가?
- 위험 동작에 확인과 복구 경로가 있는가?

### 반응형

- 고정 폭, overflow, 잘림, 과도한 줄바꿈, 작은 터치 영역이 있는가?
- 콘텐츠 우선순위가 viewport별로 유지되는가?
- breakpoint가 실제 반복값과 프로젝트 상수에 맞는가?
- 모바일 전용 UI와 데스크톱 전용 UI가 동일한 정보 구조를 유지하는가?

## 우선순위

- **P0**: 핵심 흐름 차단, 심각한 접근성 실패, 데이터 손실 위험
- **P1**: 여러 핵심 화면의 반복 문제 또는 주요 과업 혼란
- **P2**: 국소적 불일치나 개선 기회
- **P3**: 후속 정리 후보이며 현재 변경 범위에는 포함하지 않음
