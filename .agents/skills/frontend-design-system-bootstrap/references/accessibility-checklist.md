# 접근성 체크리스트

- 페이지 구조에 올바른 landmark, heading 순서, list/table 의미를 사용한다.
- 클릭 가능한 요소는 목적에 맞는 `button` 또는 `a`를 사용하고 div 클릭 핸들러를 피한다.
- 모든 기능을 키보드로 도달·실행·종료할 수 있게 한다. focus trap과 focus return이 필요한 overlay를 확인한다.
- `:focus-visible` 표시가 배경과 충분히 구분되고 잘리지 않게 한다.
- icon-only control, 이미지, 입력, 상태 메시지에 정확한 accessible name을 제공한다. 장식 이미지는 숨긴다.
- label과 오류를 입력에 연결하고, 오류 발생 시 위치와 해결 방법을 전달한다.
- 텍스트·아이콘·상태 색상의 대비를 확인하고 색상만으로 의미를 전달하지 않는다.
- disabled와 read-only를 구분하며, 상태 변화와 비동기 결과를 필요한 경우 live region으로 알린다.
- 터치 대상 크기와 인접 대상 간 간격을 모바일에서 확인한다.
- 확대, 320px 폭, 긴 한국어/영문 텍스트, 글자 크기 증가에서 내용 손실이 없는지 확인한다.
- motion과 자동 재생은 `prefers-reduced-motion`과 일시정지 요구를 고려한다.
- 대표 화면을 실제 브라우저에서 keyboard-only로 점검하고, 가능하면 프로젝트의 기존 자동 접근성 검사를 함께 실행한다.

자동 도구 결과만으로 통과를 선언하지 마라. 수동 키보드 흐름과 화면 구조 확인 결과를 `docs/UI_AUDIT.md`에 기록하라.
